Components

This page defines the standard layout patterns for dashboard content, including KPI cards, chart panels, and table grids. All dashboards should follow these patterns for consistency and usability.

▼

1. KPI Cards

Purpose: KPI cards are placed at the top of dashboards for importance. They provide at-a-glance metrics with performance indicators.

KPI Card Requirements

✓ Must Include

  • Title/Label: Clear metric name (10px, uppercase, gray)
  • Data Value: Large, bold number (20px, bold, navy)
  • Performance Indicator: Badge showing variance, comparison to target, market average, or benchmark
  • Context Text: Additional information like "Market avg: 780" (10px, gray)
  • Optional: KPI cards may include clickable links for drill-down details. Use subtle styling (underline on hover) to indicate interactivity.

Purpose: Charts visualize data trends, distributions, and comparisons. They must be clear, interactive, and provide context.

Chart Requirements

✓ Must Include

  • Bold Title: Uppercase, 14px, bold (700), color #003D5C, letter-spacing 0.4px
  • Subtitle/Context: Additional info like benchmarks or performance (10px, gray #6b7280)
  • Legend: Small solid squares (10px × 10px, 2px border-radius) with 11px labels, gray text (#6b7280)
  • Axis Labels: Both X and Y axes with 10px font, gray (#9ca3af for values, #6b7280 for labels)
  • Hover Tooltips: Display data values on hover with units
  • Optional Dropdown: For filtering (4px/8px padding, 11px font, light border #e5e7eb)

4. Opportunity Boxes

Purpose: Opportunity boxes highlight actionable insights and improvement areas. They use dark blue backgrounds with white text to draw attention.

Opportunity Box Requirements

✓ Must Include

  • Title: Clear, action-oriented headline (13px, bold, white)
  • Subtitle: Member count and context (11px, light blue #e0e7ff)
  • Badge: Impact level or urgency indicator (top-right corner)
  • Action Links: "Details →" and "Member List →" links (11px, white, bold)
  • Dark Blue Background: #00548C with #003D5C border
  • 3-Column Grid: Display 3 boxes per row with 12px gap

Table Grid Requirements

✓ Must Include

  • Panel Header: Title on left, Export button on right (dark blue #00548C, white text)
  • Header Row: Uppercase, 10px, gray (#9ca3af), light background (#fafbfc), sortable with click
  • Sort Indicators: Up/down arrows (↑↓) in Centene Blue (#00548C) when active, neutral (⇅) when inactive
  • Data Cells: 11px font, dark gray text (#374151), proper alignment
  • Hover State: Light background (#f9fafb) on row hover, (#f0f4f8) on header hover
  • Status Pills: Color-coded indicators using official Centene colors
  • Right Alignment: Use .r class for numeric columns
