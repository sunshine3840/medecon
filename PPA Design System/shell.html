Shell Specifications

Dimensions

  • Sidebar: 180px fixed width
  • Topbar: 40px fixed height
  • Filter Panel: 220px fixed width
  • Content Area: Flexible (fills remaining space)

Colors

  • Sidebar: #00558C (Centene Blue)
  • Topbar: linear-gradient(90deg, #003D5C 0%, #00548C 50%, #0066A1 100%)
  • Filter Panel: #ffffff (White)
  • Content Area: #f0f2f5 (Light Gray)

Typography

  • Font Family: 'Segoe UI', system-ui, sans-serif
  • Dashboard Title: 13px, bold, 0.2px letter-spacing
  • Sidebar Header: 12px, bold, uppercase, 0.5px letter-spacing
  • Nav Items: 13px, regular
  • Filter Title: 12px, bold
  • Filter Labels: 11px, bold
  • Filter Inputs: 11px
  • Dept/Refresh Info: 9px, regular

Spacing

  • Content Padding: 16px all sides
  • Sidebar Header: 12px 16px padding
  • Nav Items: 8px 16px padding
  • Filter Header: 12px 16px padding
  • Filter Content: 12px padding wrapper
  • Filter Groups: 14px bottom margin
  • Topbar Dividers: 12px left/right margin
  • Icon Gap: 8px between icons
💡 Implementation Tips
  • Use the template HTML file as a starting point for new dashboards
  • Use position: fixed for sidebar and filter panel to keep them visible during scroll
  • The content area should be VERTICALLY scrollable if content exceeds viewport height
  • The content area should NEVER be horizontally scrollable
  • Maintain consistent z-index values: sidebar (10), topbar (20), filters (10), content (1)
