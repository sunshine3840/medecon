Best Practices

Guidelines for creating effective, consistent, and user-friendly PPA dashboards.

Dashboard Design Guidelines

✓ Do

  • Place KPIs at the top of dashboards
  • Use consistent 121px height for KPI cards
  • Always include performance indicators
  • Provide context (market avg, target, benchmark)
  • Use primary colors for charts
  • Label all chart axes
  • Enable hover tooltips on charts
  • Include interaction instructions when needed

✗ Don't

  • Use colored backgrounds on KPI cards
  • Omit performance indicators from KPIs
  • Create KPIs without context text
  • Use inconsistent KPI card heights
  • Create charts without axis labels
  • Use non-standard colors for charts
  • Hide interaction capabilities from users
  • Forget hover tooltips on interactive charts
