Typography

Font Family

All dashboards must use Segoe UI or Arial as the primary font family. These fonts ensure consistency and readability across all platforms.

Primary Font
Segoe UI
Preferred for all dashboard content
Fallback Font
Arial
Use if Segoe UI is unavailable

Font Size Range

Font sizes across the design system range from 9px (minimum) to 32px (maximum).

Element Font Size Usage
Page Titles 32px Main page headings
KPI Values 20px Large metric values
Chart Titles 14px Panel and chart headings
Body Text 13px Standard dashboard text
Table Data 11px Table cells and labels
KPI Labels / Badges 10px Small labels and indicators
Metadata / Timestamps 9px Smallest text (minimum size)
